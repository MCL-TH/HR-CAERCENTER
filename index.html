สูตร Excel (Excel Formula)

วางสูตรนี้ใน Excel เพื่อสร้างโครงสร้าง JSON (สมมติ A=ID, B=ชื่อ, C=ตำแหน่ง, D=แผนก):

="{"&CHAR(34)&"id"&CHAR(34)&":"&CHAR(34)&A2&CHAR(34)&","&CHAR(34)&"name"&CHAR(34)&":"&CHAR(34)&B2&CHAR(34)&","&CHAR(34)&"position"&CHAR(34)&":"&CHAR(34)&C2&CHAR(34)&","&CHAR(34)&"dept"&CHAR(34)&":"&CHAR(34)&D2&CHAR(34)&"},"

วิธีใช้งาน:

  1. ลากสูตรลงมาจนครบทุกแถวใน Excel
  2. ก๊อปปี้ข้อมูลที่ได้ทั้งหมดมาวางในช่อง Importer (Dashboard)
  3. ใส่ [ ] ครอบหัวท้าย (เช่น [ {ข้อมูล1},{ข้อมูล2} ])
  4. กด Sync Data
