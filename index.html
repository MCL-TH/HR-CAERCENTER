🧮 Excel Helper

คัดลอกสูตร Excel ด้านล่างไปใช้ในไฟล์ข้อมูลพนักงาน สูตรนี้จะสร้างข้อความ JSON สำหรับพนักงานแต่ละคน จากนั้นก๊อปปี้ผลลัพธ์ทั้งหมดมาวางในแท็บ Import แล้วกด Sync ได้เลย

📋 โครงสร้างไฟล์ Excel ที่รองรับ:

• คอลัมน์ A = รหัสพนักงาน (Employee ID)

• คอลัมน์ B = ชื่อ-นามสกุล (Name)

• คอลัมน์ C = ตำแหน่ง (Position)

• คอลัมน์ D = แผนก (Department)

• แถวแรกของข้อมูล = แถว 2 (แถว 1 = Header)

📌 สูตรสร้าง JSON ต่อแถว (วางในคอลัมน์ E)

="{""id"":"""&TEXT(A2,"0000000")&""",""name"":"""&B2&""",""position"":"""&C2&""",""dept"":"""&D2&"""}"

ผลลัพธ์ในแต่ละเซลล์ E จะเป็น JSON object ของพนักงาน 1 คน

📌 สูตรรวม JSON Array (วางในเซลล์ G2)

="["&TEXTJOIN(",",TRUE,E2:E1000)&"]"

เซลล์ G2 จะรวมทุกแถวเป็น JSON Array สมบูรณ์ → ก๊อปปี้ค่านี้ไปวางใน Import แล้วกด Sync

📖 ขั้นตอนการใช้งาน

  1. 1เปิดไฟล์ Excel ข้อมูลพนักงาน ให้คอลัมน์เป็นไปตามโครงสร้างด้านบน
  2. 2วางสูตรแรกในเซลล์ E2 แล้ว Fill Down ลงไปจนถึงแถวสุดท้ายของข้อมูล
  3. 3วางสูตรที่สองในเซลล์ G2 เพียงเซลล์เดียว
  4. 4คัดลอก ค่า (Value) จากเซลล์ G2 มาวางในช่อง Import แล้วกด Sync

💡 ตัวอย่าง JSON ที่ถูกต้อง

[ {"id":"0000001","name":"สมชาย ใจดี","position":"วิศวกร","dept":"ผลิต"}, {"id":"0000002","name":"สมหญิง รักดี","position":"HR","dept":"บุคคล"} ]
