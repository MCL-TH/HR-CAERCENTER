ระบบจัดการฐานข้อมูลพนักงาน Maersk

จัดการข้อมูลพนักงาน, กำหนดสิทธิ์ และอัปเดตข้อมูลโครงสร้างองค์กร

ฟิลด์ที่รองรับ:

  • id (7 หลัก)
  • name (ชื่อ-นามสกุล)
  • position (ตำแหน่ง)
  • dept (แผนก)

 

  • cluster (Cluster)
  • level (Job Level)
  • empDate (วันที่เริ่มงาน)
  • role (User / SuperUser)

คำแนะนำ:

  • ระบบจะอัปเดตข้อมูลตาม ID โดยไม่ลบไซส์เสื้อผ้าเดิมที่เลือกไว้
  • กำหนด `SuperUser` ในฟิลด์ role เพื่อให้สิทธิ์ผู้ใช้เข้าถึงหน้าจัดการได้

ลบรายชื่อพนักงานออกจากระบบ:

ข้อมูลพนักงานและประวัติการลงทะเบียนจะถูกลบถาวร
